# Privacy Overview

Backboard Studio collects minimal data necessary to serve and improve the product. Features that could share data are either opt-in or can be disabled.

- **Telemetry:** Backboard Studio collects only the data necessary to understand usage and fix issues. Client-side telemetry can be disabled in settings. See [Telemetry](../telemetry.md).

- **AI:** Backboard Studio doesn't store your prompts or code context. Data sharing for AI improvement is opt-in, and each share is a one-time action; it doesn't grant permission for future collection. You can use Backboard Studio's AI features without sharing any data with Backboard Studio. See [AI Improvement](./ai-improvement.md).

- **Open source:** Backboard Studio's codebase is public. You can inspect exactly what data is collected and how it's handled. If you find issues, [report them](https://github.com/backboard/ide/issues).

On Backboard Business, administrators can enforce these settings org-wide so members can't opt in to data sharing individually. See [Privacy for Business](../business/privacy.md).
