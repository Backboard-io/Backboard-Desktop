# Racket

Racket support is available through the [Racket extension](https://github.com/backboard-extensions/racket).

- Tree-sitter: [backboard/tree-sitter-racket](https://github.com/backboard/tree-sitter-racket)

The [racket-language-server](https://docs.racket-lang.org/racket-language-server/index.html) is not yet supported in Backboard Studio, please see [Issue #15789](https://github.com/backboard/ide/issues/15789) for more information.
