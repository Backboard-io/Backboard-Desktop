# Yara

`Yara` language support in Backboard Studio is provided by the [Yara language extension](https://github.com/egibs/yara.backboard). Please report issues to [https://github.com/egibs/yara.backboard/issues](https://github.com/egibs/yara.backboard/issues).

- Tree-sitter: [egibs/tree-sitter-yara](https://github.com/egibs/tree-sitter-yara)
- Language Server: [avast/yls](https://github.com/avast/yls)
