# Backboard — “What Will You Build?”

## Launch-film master script

- **Runtime:** 90 seconds exactly
- **Master:** 3840×2160, 30 fps, 16:9
- **Social-safe crop:** keep all essential copy and faces inside the centered 2160×2160 region
- **Structure:** panic → silence → human choice → founder proof → Backboard reveal → product proof → challenge
- **Narration:** one calm, grounded voice; never “movie trailer” theatrical
- **Score:** original/licensed instrumental; no vocals
- **Product footage:** real Backboard captures for every readable UI beat
- **News footage:** fictional/commissioned anchors on generic sets; no real outlet logos and no fabricated quotes attributed to real reporters

## The editorial idea

The opening behaves like an anxiety algorithm. One alarming broadcast becomes four, then sixteen, then sixty-four, then hundreds. The film does not agree with the panic; it lets the panic become absurdly overwhelming, cuts the power, and asks a more useful question: if AI can do more of the execution, what will a person choose to create?

The founder clips form a three-line argument:

1. AI itself is not the differentiator; using it is.
2. This is an unusually good moment to start.
3. Ideas, rather than tools, should become the limit.

Backboard is then revealed as the place where that agency becomes visible: one idea becomes a plan, real files, running tools, reviewed changes, and parallel work.

## Capture and finishing rules

1. Use authentic Backboard UI and real tool activity. Never show generated placeholder prose inside readable product shots.
2. Keep **Simple**, **Editor**, and **Advanced** labels and feature names consistent with the shipping build.
3. Show an actual test passing, an actual changed-files review, and an actual browser result. The film’s promise depends on cause and effect being legible.
4. Record UI at 4K or higher with a 2× interface scale that survives the 1080p review export.
5. Do not use fake GitHub, Figma, OpenAI, Anthropic, NVIDIA, or news-network UI/branding as set dressing.
6. Clear commercial rights for all founder footage, music, fonts, and stock/generative assets. Short duration does not automatically make third-party footage free to use. If a clip cannot be cleared, replace it with licensed text-on-screen attribution or an original Backboard founder interview—never a synthetic impersonation.
7. Before picture lock, confirm the final product name (`Backboard` versus `Backboard Studio`) and launch URL. This script intentionally uses **Backboard** because that is the current repository/product name.
