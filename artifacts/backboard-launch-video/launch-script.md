# Backboard Studio — Launch Film

## Master brief

- **Runtime:** 75 seconds
- **Master:** 3840×2160, 30 fps, 16:9; review export at 1920×1080
- **Format:** UI-led product film, no presenter and no laptop/device mockup
- **Narration:** None in the primary cut. Kinetic type carries the message so the product stays central.
- **Music:** Original 112 BPM electronic score in E minor; restrained, precise, optimistic; no vocals.
- **Look:** Graphite black, cool white type, Backboard blue accents, warm amber only for blocked/warning states.
- **Motion:** Slow 2–4% pushes on whole screens; decisive 6–10 frame panel wipes; no elastic motion and no artificial cursor trails.
- **Product truth:** Use real Backboard UI for every readable feature beat. Higgsfield shots are only transitional hero motion.
- **Exclusion:** Jarvis is never shown, named in on-screen copy, or represented by a voice/canvas visual.

## Panel choreography rules

### Simple

- Left sidebar always shows projects and sessions; never crop it completely out.
- The main session remains the visual anchor while the right panel changes.
- Composer/model/context controls must be readable before any request is sent.
- Tool activity should be real and compact: two or three rows, not a wall of text.

### Right feature panel

- **Files:** reveal workspace structure and active/changed files.
- **Review:** show actual additions/deletions and the changed-file list.
- **Terminal:** show one meaningful command and a successful final state.
- **Browser:** show live preview/verification, not generic web browsing.
- **Side chat:** demonstrate a parallel question while preserving the primary task.
- Use the same camera position for all five beats so the panel feels like one coherent surface.

### Editor

- Keep code, source control/file navigation, and the agent panel visible together.
- Show active-file context being attached to the agent composer.
- Demonstrate one surgical change, then one test. Avoid a long typing montage.
- Do not frame Editor as “legacy mode”; it is the deep-control surface.

### Advanced

- Establish the full Running / Blocked / Ready board before opening menus.
- Filters must visibly include status, time, archived, agent, and repository.
- Demonstrate board/list, sort, and group options without lingering on every menu.
- Open a real card and reveal its focused workspace, statistics, and Review panel.
- Preserve the relationship between global supervision and per-task execution.

## Music specification

- **Tempo/key:** 112 BPM, E minor, 4/4.
- **Harmony:** Em(add9) → Cmaj7 → G6 → Dsus2; one chord every two bars.
- **Palette:** rounded sub bass, muted glass pluck, dry electronic kick, closed noise hat, granular interface ticks, one airy riser.
- **Arrangement:** sparse 00:00–00:12; pulse builds through Simple; full rhythm first appears in Editor; widest section is Advanced; drums drop at 01:06.500; motif resolves at the end card.
- **Mix:** −14 LUFS-I, −1 dBTP ceiling, dialog-safe midrange even though the master has no voiceover. UI effects peak 3–5 dB above the local music bed but never above −8 dBFS.

## Delivery checklist

- No Jarvis footage, backdrop, launcher, voice UI, or canvas imagery.
- No generated text inside readable UI.
- No invented provider logos or task results.
- Use authentic screenshots/captures for panel demos; Higgsfield only for mode hero shots.
- Verify every UI label at 100% before mastering.
- Export review H.264 at 20–28 Mbps and archival ProRes 422 HQ.
