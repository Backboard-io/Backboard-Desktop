# Backboard clean logo finalists

## A — Core B

`core-b-symbol.svg` and `core-b-lockup.svg` are the sharper system. The vertical stroke is the back plane, the lower chamber is the active model, and the violet square is persistent memory. This is the recommended direction.

## B — Orbit B

`orbit-b-symbol.svg` and `orbit-b-lockup.svg` use the same construction with a softer circular return path. This is the more human, approachable alternative.

## C — Wordmark / core punctuation

`wordmark-core.svg` removes the standalone symbol and uses the violet memory core as brand punctuation. This is the quietest option.

### Base palette

- Ink: `#171717`
- Memory core: `#6D5EFF`
- Warm field: `#F4F1EA`

All symbols use `currentColor` for their primary geometry, so they can reverse to white on dark backgrounds without maintaining separate SVG files. The memory core remains violet.
