# Backboard Editor design context

## Overview

This document records the established Editor-mode UI for chat file navigation, rewind, and context usage. It is a product surface for developers working beside their source files. The visual reference is the existing VS Code workbench: compact file rows, monospace source previews, restrained icon actions, and keyboard navigation. Preserve the user's theme and editor settings. No brand redesign or market-specific styling is part of this feature.

User-approved behavior is recorded in UX-CONTRACT.md. Interface strings use the existing `nls.localize` system; translations follow the repository's localization process.

## Colors

The runtime authority is `src/vs/platform/theme/common/colorRegistry.ts` and the selected theme. Chat cards and context details consume `--vscode-*` variables generated by the workbench theme service. Use `--vscode-focusBorder` for focus and the existing warning/error context classes. Do not copy a screenshot's dark colors into new tokens.

## Typography

Workbench labels inherit the workbench font. Code previews use `--monaco-monospace-font` and editor language services. Long filenames retain full hover text and their existing truncation behavior.

## Layout

Keep the shared chat widget and existing editor groups. Filename activation opens the workspace file; explicit change actions open snapshot comparisons. Hover details remain overlays and do not resize the composer. Narrow chat panes retain the same controls and scrolling owners.

## Elevation & Depth

Use the workbench hover service and existing context-detail surface; no feature-owned overlay layer or shadow system.

## Shapes

Retain the existing external-edit pill, file summary, and context indicator geometry.

## Components

- Navigation: `chatEditNavigation.ts` through `IEditorService`, shared by edit cards and attached file links.
- Changed-file summary: `ChatMultiDiffContentPart` and `WorkbenchList`.
- Change action: localized native button, Codicon diff glyph, existing hover/focus treatment.
- Context: `ChatContextUsageWidget`, `ChatContextUsageDetails`, and `IHoverService`.
- Confirmation and errors: existing workbench dialog and action error services.
- Rewind: `AgentHostSnapshotController` and `AgentHostRewind`, using text-file, readonly, and autosave services.

## Do's and Don'ts

Preserve density, theme, keyboard focus, and editor-group modifiers. Expose unavailable context as text. Use explicit historical-change actions. Do not style unavailable usage as a measured zero, invent context capacity, or report a rewind as successful before file and editor restoration complete.
