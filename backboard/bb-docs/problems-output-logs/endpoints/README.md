# Problems, Output, And Logs Endpoints

## Services

- Marker service owns diagnostics and marker events.
- Output service owns output channel creation, selection, and lifecycle.
- Log service owns log levels, log files, and log output.

## Contribution Points

- Problem matchers and problem patterns from extensions/tasks feed Problems.
- Language providers and diagnostics collections feed marker services.
- Extensions create output channels through VS Code APIs.

## Commands

- Problems navigation and filtering commands are registered by marker/problem contributions.
- Output/log commands are registered by output/log workbench contributions.

## Network Endpoints

- Problems/output/logs are local presentation surfaces.
- Remote logs or diagnostics come through remote/provider services rather than a shared public HTTP endpoint.

### Code Pattern To Preserve

```ts
// Keep endpoint ownership explicit. Prefer command/service/provider contracts
// over reaching into another feature's private storage or DOM.
class FeatureAction extends Action2 {
  constructor() {
    super({
      id: 'owner.feature.commandId',
      title: localize2('feature.command.title', "Human Readable Command"),
      precondition: undefined,
      menu: { id: MenuId.CommandPalette }
    });
  }

  override async run(accessor: ServicesAccessor): Promise<void> {
    const commandService = accessor.get(ICommandService);
    await commandService.executeCommand('owner.lowerLevelCommand');
  }
}
```
