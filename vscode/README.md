# Backboard IDE

Backboard IDE is the Backboard-focused editor fork in this repository.

This workspace contains the Backboard editor shell, Backboard chat wiring, agent/sandbox surfaces, packaging resources, and the Backboard bridge code used by the local IDE.

## Development

Use the existing repository scripts and docs for building, running, testing, and packaging this editor. The product-facing name in this fork is Backboard IDE.
