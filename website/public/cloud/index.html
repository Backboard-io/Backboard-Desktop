FAQs

VIEW DOCUMENTATION ↗
Does this page deploy an EC2 instance?

No. Backboard currently connects to an existing compatible agent server. Provision the machine, build the runtime, and configure provider credentials on the host before connecting.

Do my local files move to the cloud?

No. Clone or copy your project onto the remote machine first. Choose that remote folder when you create the new task.

What do I pay for?

Your cloud provider bills for your infrastructure. Model providers bill according to your accounts and usage. This website does not sell hosting or collect payment.

Can I switch between local and cloud?

Yes, for new tasks. Select Local or a saved host from the location chip. Existing conversations keep the host they started on.

Will tasks survive a disconnection?

That depends on the remote server configuration and process supervision. Test your host’s behavior before relying on unattended execution.
